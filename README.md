### 🛰️ Project 01 — Cognitive Opportunistic LEO-PNT Receiver

<table>
<tr>
<td>

```
🎯 CLIENT    : Ministry of Defence — Defence Space Agency, HQ IDS
🔬 STACK     : Python | Raspberry Pi | RTL-SDR | Signal Processing
🏆 OUTCOME   : Smart India Hackathon 2025 National WINNER
📌 STATUS    : Functional prototype deployed & demonstrated nationally
```

**The Problem:** GNSS systems are vulnerable to jamming, spoofing & signal attenuation.  
**The Solution:** A cognitive receiver that leverages non-PNT LEO satellite signals as alternative navigation anchors.

**What I built:**
- 🔭 RF front-end + Software Defined Radio (SDR) signal processing chain on Raspberry Pi
- 📡 Doppler shift estimation & timing synchronization modules
- 🧭 System-level compensation models for GNSS-denied environments
- ⚡ Real-time embedded prototype with hardware-software integration
